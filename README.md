🎯 Overview
Smile Dental Care is a fully responsive, single-page application designed for a modern dental practice. It showcases the practice's services, patient testimonials, and provides an easy way for patients to book appointments.

This project demonstrates:

Clean, professional UI/UX design

Mobile-first responsive architecture

Smooth animations and transitions

Contact forms with validation

SEO-optimized meta tags

✨ Features
✅ Responsive Design — Looks great on desktop, tablet, and mobile

✅ Appointment Booking — Integrated contact form for patient requests

✅ Service Showcase — Display all dental services with icons

✅ Patient Testimonials — Carousel with patient reviews

✅ Modern Animations — Smooth scroll and entrance animations

✅ Interactive Map — Location embed with Google Maps

✅ Emergency Banner — Same-day emergency callout

✅ SEO Optimized — Proper meta tags and semantic HTML

✅ Accessible — ARIA labels and keyboard navigation
